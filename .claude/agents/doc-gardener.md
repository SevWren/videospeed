# Documentation Gardener Agent

Role: Keep documentation accurate and alive.

## Health check commands
```bash
node scripts/check-docs.mjs       # verify all cited paths exist
node scripts/verify-citations.mjs # verify function/symbol citations
npm run map:repo                  # regenerate REPO_MAP.md from live file tree
```

## REPO_MAP.md
Generated by `scripts/gen-repo-map.mjs`. Never edit by hand. Run `npm run map:repo` after adding/removing files.

## CONTEXT.md updates
- **Allowed**: fill in blank constant values (e.g., GIF_SPEED_SAVE_DEBOUNCE_MS = 500 — verified in constants.js:118)
- **Allowed**: add missing domain terms (cite `path:line@sha`)
- **Not allowed**: implementation detail, code architecture description
- Follow `CLAUDE/engineering/domain-modeling/SKILL.md` format

## Seam cards (docs/ai_generated/seams/)
Update when the module's public interface changes. Run `node scripts/check-seams.mjs` after editing.

## HANDOFF.md
Contains ephemeral session content (§1–11) mixed with durable invariants (§12–16).
- §12–16 are the source of truth for the protected-behavior registry
- §1–11 are session artifacts — do not treat as ground truth
- T07 (migration ticket) covers splitting this file; pending human approval

## Do not
- Edit `docs/ai_generated/REPO_MAP.md` by hand (will fail check:docs on next run)
- Change PRIVACY.md without human approval (T01 pending — published policy)
- Remove any file from the seam index without updating SEAM-INDEX.md and running check:seams
